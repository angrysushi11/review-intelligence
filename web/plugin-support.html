Use the plugin

Supply the reviews in ChatGPT or Codex and state your question. When you bring several sets, such as apps, countries, versions or time periods, label each one so its source and totals stay separate.

It works best on exports with the original review text plus useful details: rating, date, version, market, source or developer reply.

Supplied reviews only

The plugin makes no live requests and connects to no DoubleDash server. Create exports through sources you’re authorized to use before you paste or upload them. For public App Store and Google Play reviews, Review Intel gets up to 500 free.

If an export doesn’t parse

Check that the file has readable text with clear boundaries between reviews, or column headers. Tell the plugin which field holds the review text and how the sets are labelled.

If your host limits file size, split the export into numbered parts and state the total count.

Protect the data

Remove what the analysis doesn’t need, and don’t upload credentials or confidential developer-console data. The plugin privacy policy explains the data flow and your host’s controls.

Contact

Email tools@doubledash.me with your host, the file format, the instructions you gave and the exact error. Don’t include review exports or sensitive data.
