Use the plugin

Supply a review export in the ChatGPT or Codex conversation and state the question you want answered. If you provide several apps, countries, versions, or time periods, label each set clearly so the analysis can keep its sources and denominators separate.

The plugin works best when the export preserves the original review text and any useful rating, date, version, market, source, or developer-reply fields.

Supplied reviews only

This skills-only plugin performs no live retrieval or DoubleDash server connection. Create an export through a source or tool you are permitted to use, then paste or upload it.

If an export does not parse cleanly

Check that the file contains readable text and consistent review boundaries or column headers. Tell the plugin which field contains the review text and how separate datasets are labelled. If the host reports a file or conversation limit, divide the export into clearly numbered parts and preserve the total supplied count.

Protect the data

Remove information that is unnecessary for the analysis and do not upload credentials or confidential developer-console data. Read the plugin privacy policy for the exact data flow and host controls.

Contact

Email tools@doubledash.me with the host you used, the file format, what you asked the plugin to do, and the exact error message. Do not attach the review export or include personal, confidential, or sensitive review data in a support email.
