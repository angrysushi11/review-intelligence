Review Intelligence

Three ways to use it

Use the route for the tool where you want to analyze the reviews.

Custom GPT

Export reviews, then upload

The Custom GPT cannot call Review Retriever directly. This is the only route that needs a Markdown file.

  1. Paste the app link below, choose the country, and select Extract Reviews.
  2. Copy or download the generated Markdown file.
  3. Upload the file to the Custom GPT and ask for review analysis.

Claude

Connect once, then paste the app link

Claude retrieves and analyzes the reviews in the same chat. After setup, you do not need to return here or create an export.

Available on Free, Pro, Max, Team, and Enterprise. Free accounts can add one custom connector.

  1. Download the Review Intelligence skill. Open Claude Skills and select Add → Upload a skill. Choose the ZIP and turn the skill on.
  2. Connect Review Retriever. Leave the optional OAuth client fields empty, select Add, then Connect.
  3. Start a new chat. Use + → Connectors to enable Review Retriever. Paste the app link and country; approve the read-only retrieval tool when Claude asks.
Download the skill Open Claude Skills Connect Review Retriever
First prompt Analyze reviews for [app URL] in the US market. Use Review Retriever, then give me the first useful read.

Codex / Work

Install once, then paste the app link

The Review Intelligence plugin includes the analysis skill and the Review Retriever connection. No Markdown export is needed.

The GitHub release is available for Codex. A separate public-directory listing for Work is still pending.

  1. Add the DoubleDash plugin marketplace in Codex.
  2. Install Review Intelligence, then start a new task so the plugin loads.
  3. Paste the App Store or Google Play link, add the country if it matters, and ask for review analysis.
codex plugin marketplace add angrysushi11/review-intelligence --ref main codex plugin add review-intelligence@doubledash
