    Questions

    Do I need App Store Connect or Google Play Console?

    No. Review Intel reads public store listings, so it doesn’t need a developer account, store-console access or an API key.

    Can I get more than 500 reviews?

    For Google Play, yes: connect Claude or Codex and it keeps pulling the next batch until the store has no more pages. Apple’s public feed stops earlier. No public source can promise every review ever posted.

    Does it work on a competitor’s app?

    Yes, for any app with a public App Store or Google Play listing.

    The App Store gave me only a few reviews. Why?

    Apple’s public review feed can be flaky. If an export comes back with 0 or only 10 reviews, try again in a minute or pick another country.

    What file format do I get?

    Markdown. Analyze copies it for you together with the prompt, or you can copy it yourself or download a .md file. There’s no CSV, Excel or JSON export on this page.

    Is this an app review scraper?

    People often call a public review exporter that. Review Intel reads public written reviews from supported store listings. It doesn’t sign in anywhere or touch private developer-console data.
