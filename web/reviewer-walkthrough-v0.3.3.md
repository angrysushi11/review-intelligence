# Review Intel reviewer walkthrough

This is a silent, captioned screenshot sequence made from actual 1280×720
captures of the local reviewer demonstration. The positive retrieval screens
display captured direct, read-only MCP output. Their analytical synthesis is
authored illustrative analysis and is labelled separately from the retrieval
record. The supplied-row cases use only the rows displayed. The three negative
screens are scripted expected-routing controls that make no retrieval.

The sequence is not a ChatGPT recording, continuous live capture, model
evaluation, or a claim about model tool selection or wording. It does not claim
demand, revenue, conversion, retention, or causality.

Spotify coverage is deliberately bounded: two sequential 150-record Google Play
batches (300 total) are shown, and the second response still reports
`has_more: true`. Additional pages remain. The plugin test case is being amended
to this bounded two-batch coverage.

No screenshot pixels were changed apart from H.264 video encoding. Captions are
an embedded subtitle track; there is no audio or fabricated motion.
