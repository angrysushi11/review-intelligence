Connect your AI client

The read-only MCP endpoint is https://www.willthiseverwork.com/review-intel/mcp. It does not require a store login or API key. For client-specific setup steps, see the MCP setup guide.

Report a connection or retrieval issue

Email tools@doubledash.me. Include the AI client, public app-store URL, country, approximate time, and exact error message. Do not send passwords, store credentials, private exports, or sensitive personal data.

Check the review coverage

Public storefront feeds may omit reviews or limit pagination. If an answer seems incomplete, check the reported source, country, sort order, review count, and coverage before drawing a conclusion. Apple and Google control their storefront feeds, so the available sample can change.
